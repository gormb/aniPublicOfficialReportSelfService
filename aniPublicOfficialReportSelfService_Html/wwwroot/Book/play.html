      ThoughtsKeep the mapping as data, not code: feature ↔ level mask, plus optional anchors into the other structures (book, chapter, page, paragraph, word), so one feature list drives navigation, help text and AI tools alike.
    6. One axis, two directions
      ThoughtsZoom out (Ord → Bokhylla) trades detail for overview; zoom in trades overview for detail. Each level knows its coarser parent and finer child, so one-step navigation is always defined.
    7. Levels as data, not headings
      ThoughtsTreat pl0…pl8 as an ordered array with a stable numeric id (plN), so features can reference levels by number and bitmask instead of by duplicated markup.
